아래 순서대로 진행하세요. 명령은 한 줄씩 복사해 붙여 넣으면 되고,
bash, zsh, PowerShell 어디서나 똑같이 동작합니다.

[1] Pod 가 모두 뜰 때까지 기다리기 (보통 1~5분)

    kubectl -n {{ $ns }} wait --for=condition=Available deployment --all --timeout=5m

    Deployment 마다 "condition met" 한 줄씩 나오면 준비된 것입니다.
    진행 상황은 kubectl -n {{ $ns }} get pods 로 볼 수 있습니다.

[2] 브라우저로 접속하기
{{- if .Values.ingress.enabled }}

    {{ if .Values.ingress.tls }}https{{ else }}http{{ end }}://{{ .Values.ingress.host }}
{{- else if eq .Values.gateway.service.type "NodePort" }}

    Docker Desktop        http://localhost:{{ .Values.gateway.service.nodePort }}
    그 밖의 클러스터      http://<노드 IP>:{{ .Values.gateway.service.nodePort }}
                          노드 IP: kubectl get nodes -o wide 의 INTERNAL-IP
{{- else if eq .Values.gateway.service.type "LoadBalancer" }}

    http://<EXTERNAL-IP>:8000
    EXTERNAL-IP: kubectl -n {{ $ns }} get svc gateway (할당까지 1~2분 걸릴 수 있음)
{{- end }}

    주소가 열리지 않으면 아래 명령을 켜 둔 채로 http://localhost:8000 에 접속하세요.
    kubectl -n {{ $ns }} port-forward svc/gateway 8000:8000
{{- if and .Values.auth.cookieSecure (not .Values.ingress.tls) }}

    ⚠ localhost 가 아닌 http:// 주소로 접속하면 로그인 쿠키가 버려져
      로그인이 되지 않습니다. 그때는 helm upgrade 에
      --reuse-values --set auth.cookieSecure=false 를 붙여 다시 적용하세요.
{{- end }}

[3] admin 계정으로 로그인하기

    ID         {{ .Values.admin.email }}
{{- if .Values.admin.password }}
    Password   설치할 때 admin.password 로 정한 값
{{- else }}
    Password   아래 명령이 출력하는 문자열 (설치할 때 무작위로 만든 값)

    kubectl -n {{ $ns }} get secret {{ include "kubeast.secretsName" . }} -o go-template='{{ "{{" }}.data.DEFAULT_ADMIN_PASSWORD | base64decode | println{{ "}}" }}'
{{- end }}
